# DEXLMC Work Package Skill

This repository contains a reusable Copilot Agent Skill for maintaining DEXLMC/LMC Work Package templates and Country Launch checklists.

## Skill

- [DEXLMC Work Package skill](.github/skills/dexlmc-wp/SKILL.md) — component management, Work Package and Sub-task maintenance, template comparison, and Country Launch import procedures.

The skill is designed for Jira Digital workflows in the DEXLMC and DEX projects. It includes checks for permissions, parent/component relationships, issue scope, and board visibility.
